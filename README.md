# Free Writer

A simple, **ad-free** online text editor for privacy-focused writing. Write with complete privacy, no ads, no tracking.

## Features

- 📝 **Full-featured text editor** - Bold, italic, underline, strikethrough, and list formatting
- 🔒 **Privacy-first** - No ads, no tracking, no data collection
- 👁️ **Hide/Reveal mode** - Hide your text like a password field for extra privacy
- 🎨 **Dark/Light theme** - Beautiful dark and light themes for comfortable writing
- ⌨️ **Keyboard shortcuts** - Quick access to all formatting options
- 📊 **Live statistics** - Real-time character and word count
- 📱 **Responsive design** - Works perfectly on desktop, tablet, and mobile
- ⚡ **Fast & lightweight** - Pure HTML/CSS/JavaScript with no external dependencies

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+U` | Underline |
| `Ctrl+Shift+X` | Strikethrough |
| `Ctrl+Shift+7` | Numbered List |
| `Ctrl+Shift+8` | Bullet List |
| `Ctrl+\` | Clear Formatting |
| `Ctrl+H` | Toggle Hide/Reveal |
| `Ctrl+A` | Select All |

## Getting Started

Simply open `index.html` in your web browser. No installation or setup required!

## Privacy

Your data stays on your device. Free Writer:
- Does not store any data on servers
- Does not use cookies for tracking
- Does not contain any analytics
- Does not show ads
- Does not require account creation
